## 一、核查目的
围绕供应链协同相关组织层级、部门负责人、流程主线、采购到货协同以及相关证据、访谈、问题记录进行串联核查，重点识别以下事项：
- 组织、流程、职责、问题、证据之间是否前后对应；
- 是否存在口径冲突或表述层级不一致；
- 是否存在材料表述先于证据、直接形成结论的情况；
- 输出待补材料项与待进一步复核项。

**说明**：本纪要仅用于核查和标记，不直接形成诊断结论。

## 四、流程主线核查
当前与供应链协同最相关的主流程为：

**月度需求与排产评审（PROC-PLAN） → 采购与到货协同（PROC-SUPPLY） → 生产执行与异常响应（PROC-PROD） → 质量检验与放行（PROC-QA）**

### （一）月度需求与排产评审（PROC-PLAN）
- 流程类别：计划
- 归属部门：运营管理部
- 关键动作：汇总需求预测，核对产能边界，确认当月排产与备料策略
- 下游环节：采购与到货协同、生产执行与异常响应
- 当前瓶颈：需求确认与产能核对依赖多轮沟通，容易延后冻结时间

#### 当前分工记录
- 项目管理办公室 / 陈雨桐
  - 责任类型：流程统筹
  - 权限：建议权
  - 内容：推动排产评审材料收集与会议纪要落地

#### 核查标记
- 该流程作为供应链协同上游关键入口，当前仅见项目管理办公室承担流程统筹，未见客户方计划岗位或计划部门的明确责任记录。
- 项目范围中包含“计划”，但当前结构化部门台账中未发现独立计划部门。
- 该环节尚未查到直接挂接的证据、访谈或更完整的职责链条。

## 五、跨流程一致性核查
### 1. 已基本一致的地方
- 供应链管理部负责采购与到货协同，与部门职责表述基本一致。
- 周若琳作为供应链经理，承担采购变更与到货异常协调，与流程责任关系匹配。
- 上游计划—中游采购到货—下游生产—后续质量的主链条在流程依赖关系中能够串联。

### 2. 存在待澄清或不一致的地方
1. **计划环节责任主体偏弱**
   - 流程存在，但客户方计划岗位或计划部门责任不显性。
   - 当前更像由运营管理部挂总、项目管理办公室辅助承接。

2. **生产与质量边界存在混用现象**
   - 生产制造部负责人记录为“质量负责人”。
   - 质量流程也挂在生产制造部名下。
   - 组织层级、职责归属与流程责任中心之间存在口径错位风险。

3. **项目管理办公室角色介入较深**
   - 在计划和供应链流程中均承担明显动作。
   - 后续材料需区分其属于“项目推进支持角色”还是“客户日常经营正式职责”。

4. **“采购”“到货”“供应链”表述颗粒度混杂**
   - 部门层面使用“供应链管理部”。
   - 流程层面使用“采购与到货协同”。
   - 访谈主题中又偏“采购变更与异常升级路径”。
   - 若正式材料不统一颗粒度，容易出现上下层级混讲。
